# Whispering Pines Hospitality

**Whispering Pines Lodge** is a mountain-lodge reservation platform designed around a simple idea:

> Escape the noise. Reconnect with the people who matter.

The project is being built as a production-minded engineering portfolio project using Python, Django, PostgreSQL, Docker, GitHub Actions, and documented product/architecture decisions.

## Project Status
Pre-development / product and system design.

## Product Goals
- Help couples, families, and multi-generational groups plan peaceful mountain stays.
- Recommend accommodations through a guided **Stay Planner**.
- Support room availability, reservations, account management, and staff administration.
- Build with maintainability, testing, accessibility, and deployment in mind.

## Planned Stack
- Python
- Django
- PostgreSQL
- HTML / CSS / JavaScript
- Bootstrap
- Docker
- Git / GitHub
- GitHub Actions
